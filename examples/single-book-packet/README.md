# Single-Book Packet Example

This folder is a worked public-safe example of a `single-book deep reading` packet.

It shows what a first bounded pass can leave behind when one source owns the packet.

## Source Used

- [samples/open/demo-source.md](../../samples/open/demo-source.md)

## Workflow Owner

- `single-book deep reading`

## Why This Example Exists

The harness should not only support research intake. It should also support slow, source-owned reading.

This example is meant to show:

- how one source can own a packet
- what early write-back looks like in a single-book lane
- how the project state differs from a research-intake packet
