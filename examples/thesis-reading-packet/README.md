# Thesis Reading Packet Example

This folder is a worked public-safe example of a `thesis / non-textbook reading` packet.

It shows what the harness should leave behind when the source is argument-first rather than textbook-first.

## Source Used

- [samples/open/policy-brief-sample.md](../../samples/open/policy-brief-sample.md)

## Workflow Owner

- `thesis / non-textbook reading`

## Why This Example Exists

- to give the public repo a clearly non-finance example
- to show what argument-first write-back looks like
- to make the fourth workflow mode concrete instead of leaving it as docs-only
