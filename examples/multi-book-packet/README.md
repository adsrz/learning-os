# Multi-Book Packet Example

This folder is a worked public-safe example of a `multi-book synthesis` packet.

It shows what the harness should leave behind when more than one source is in scope and the packet must preserve both overlap and difference.

## Sources Used

- [samples/open/demo-source.md](../../samples/open/demo-source.md)
- [samples/open/demo-source-2.md](../../samples/open/demo-source-2.md)

## Workflow Owner

- `multi-book synthesis`

## Why This Example Exists

This example is meant to show:

- how two sources can both stay visible inside one packet
- how synthesis differs from a single-source packet
- how durable write-back can preserve common structure and tension at the same time
