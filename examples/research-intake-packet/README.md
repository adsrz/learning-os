# Research Intake Packet Example

This folder is a fully worked public-safe example packet.

It shows what the harness should leave behind after a single bounded pass on a new research-style source.

## Source Used

- [samples/open/demo-source.md](../../samples/open/demo-source.md)

## Workflow Owner

- `research / paper workflow`

## Why This Example Exists

Templates show the shape of the system. This example shows the result after the shape has been used.

It is meant to answer:

- what does a real packet look like?
- what gets written back after a bounded pass?
- how much structure should survive beyond chat?

## Included Outputs

- `project.md`
- `session-log.md`
- `open-questions.md`
- `distinctions.md`

These files are intentionally small, but they are meant to feel real rather than blank.
