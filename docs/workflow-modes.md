# Workflow Modes

These modes belong to the `teaching` overlay.

Setup, validation, public/private boundary checks, and repo maintenance belong to `system-ops` and should not be forced into one of these study modes.

## Single-Book Deep Reading

- one primary source
- mechanism-first reading
- cumulative glossary, distinctions, evidence, and questions
- best fit when one source should remain authoritative

See [single-book-deep-reading.md](examples/single-book-deep-reading.md).

## Multi-Book Synthesis

- several sources routed into one structured project
- preserve source differences instead of flattening them
- useful for subjects where one book is not enough

See [multi-book-synthesis.md](examples/multi-book-synthesis.md).

## Thesis / Non-Textbook Reading

- argument-heavy, essay-like, or theory-first reading
- emphasize thesis maps and conceptual pressure-testing
- useful when chapter progression alone is not the real structure

See [thesis-reading.md](examples/thesis-reading.md).

## Research / Paper Workflow

- papers, reports, articles, and captured sources
- intake, classification, routing, and later study
- useful when source acquisition and provenance matter as much as the reading itself

See [research-workflow.md](examples/research-workflow.md).
