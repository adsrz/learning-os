# Thesis Project Template

This folder is a minimal public-safe template for `thesis / non-textbook reading`.

Copy it when the source is argument-first, theory-first, or institution-first rather than textbook-linear.

This template is for durable study write-back. It is not the target surface for `system-ops` tasks such as setup, validation, or public boundary checks.

## Included Files

- `project.md`
  Stable project identity, thesis-first route geometry, and source boundary.
- `session-log.md`
  Running record with the current frontier, frontier state, and next thesis packet.
- `open-questions.md`
  Live versus watch thesis questions and pressure-test follow-ups.
- `distinctions.md`
  Durable claim, evidence, and framing distinctions worth reusing.
- `module-map.md`
  Forward route for thesis or mechanism clusters.
- `thesis-map.md`
  Cross-packet thesis tracker for the current source.

## Suggested Usage

1. Copy this folder into your own local project area outside the tracked public repo.
2. Rename the folder for the actual project.
3. Fill in `project.md`, `module-map.md`, and `thesis-map.md` first.
4. Use the harness against your own argument-first source.
5. Keep thesis structure and pressure-test paths in the local project files instead of leaving them only in chat.
