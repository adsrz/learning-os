# Learning OS

## Identity

- `Learning OS` is a local-first framework for serious self-study.
- It is designed to support durable learning workflows rather than one-off note capture.
- It is source-agnostic: the system depends on source classes and workflow modes, not on one personal source bundle.

## Public Principles

- Keep the public repo reusable.
- Keep third-party source materials out of versioned history.
- Make the repo understandable without private inputs.
- Let users plug in their own lawfully obtained materials.

## Supported Modes

- `single-book deep reading`
- `multi-book synthesis`
- `thesis / non-textbook reading`
- `research / paper workflow`
