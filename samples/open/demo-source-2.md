# Demo Source 2

This second open sample exists so the public repo can demonstrate `multi-book synthesis` without depending on private materials.

## Topic

A serious learning harness should preserve source differences instead of collapsing everything into one blended summary.

## Claims

- workflow routing matters because different source types ask for different passes
- synthesis is not the same as averaging
- durable write-back should preserve both common structure and source-specific tension

## Why This Sample Exists

- to provide a second openly included source for synthesis examples
- to show how public-safe materials can still support a real harness packet
- to make the multi-book example more concrete than a placeholder
