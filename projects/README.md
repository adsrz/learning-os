# Projects

This folder is for tracked, public-safe projects that belong to the repository itself.

It is not the default home for a user's private study packets.

## What Belongs Here

- cold-path repo-owned projects
- public packaging memory
- release-safe operating records
- durable state that should survive beyond one README rewrite or one chat turn

## What Does Not Belong Here

- private source-bound packets
- local BYOS materials
- personal runtime state
- copyrighted books, papers, PDFs, or captured materials

## Current Project

- [github-submission-cold-path](github-submission-cold-path)
  Durable cold-path owner for GitHub submission, public packaging, and release-safe repo identity.

If you want to start your own packet, begin with [templates/project-template](../templates/project-template) instead.
