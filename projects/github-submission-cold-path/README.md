# GitHub Submission Cold Path

This project owns the repo's cold-path GitHub submission and public packaging memory.

Use it when the task is about:

- README-level public claims
- GitHub description or topics
- public repo positioning
- release-safe packaging decisions
- stable AI-facing onboarding surfaces

Do not use it to drive ordinary study packets or local source-bound work.

## Files

- `project.md`
  Stable identity, scope, and operating notes for the cold path.
- `session-log.md`
  Running record of meaningful packaging and submission changes.
- `open-questions.md`
  Unresolved public-surface or submission questions worth preserving.
- `distinctions.md`
  Durable distinctions that keep the cold path separate from the hot study lane.
- `submission-record.md`
  Canonical record of key public claims, metadata intent, and update discipline.
